# Pinned deliberately.
#
# These were previously all ">=", which meant every HuggingFace rebuild pulled
# whatever versions were newest that day. The app could - and did - break with
# no code change on our side: a newer numpy/scikit-learn shifted OpenMP
# behaviour and training started dying with SIGSEGV (exit code 139).
#
# Exact pins make the deployed runtime reproducible. They need Python 3.12 or newer.
#
# When upgrading, change one line at a time and run pytest: the suite fails if
# calibration or any other step stops working, instead of it degrading silently.

# Must match `sdk_version` in README.md: HuggingFace appends
# `streamlit==<sdk_version>` to this same pip command, so any mismatch is an
# unresolvable conflict. streamlit 1.35 also capped numpy<2 / pandas<3, which
# is unsatisfiable on the Python 3.13 base image these Spaces now use.
